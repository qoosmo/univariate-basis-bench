# Archived manuscript — v1

This directory preserves the first complete manuscript draft before the
paper was rebuilt using a journal-paper structural template.

Preserved here:
- main.tex
- references.bib
- all manuscript sections
- the compiled PDF, when available
- benchmark environment metadata, when available

Not archived/moved:
- Rust source code
- benchmark programs
- Cargo files
- paper/results/
- raw benchmark outputs
- CSV/Markdown result summaries

Those remain in their original repository locations and are the experimental
record for the rebuilt manuscript.
